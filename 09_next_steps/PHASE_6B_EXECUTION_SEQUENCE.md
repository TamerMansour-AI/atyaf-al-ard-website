# Phase 6B Execution Sequence

## Principle
Do not rebuild the site in one uncontrolled pass. Execute in deliberate layers so the structure stays stable while the visual and narrative quality rises.

## Phase 6B.1 - Visual Foundation
Objective:
- establish the upgraded design system before broad page rewrites

Pages and components:
- global layout shell
- header
- footer
- buttons
- section wrappers
- card families
- evidence/source blocks

Assets needed:
- none required to begin
- optional moodboard references

Content work:
- none beyond placeholder-safe headings for testing

Expected outcome:
- a stronger visual system that can scale across the site without redoing everything twice

## Phase 6B.2 - Homepage Elevation
Objective:
- turn the homepage into a premium arrival experience

Pages and components:
- `index.html`
- homepage hero
- featured sections
- narrative support blocks
- CTA framing

Assets needed:
- homepage hero art system
- refined hero still/video treatment
- one or two supporting motif visuals

Content work:
- major homepage rewrite
- stronger section intros
- stronger support invitation

Expected outcome:
- a homepage that establishes identity, seriousness, and cinematic tone immediately

## Phase 6B.3 - Section Index Upgrade
Objective:
- give each major section its own visual identity while keeping the shared system

Pages and components:
- productions
- research
- timeline
- archive
- community
- support
- contact

Assets needed:
- section anchor visuals
- icon family

Content work:
- stronger section intros
- clearer framing copy
- selective hierarchy improvements

Expected outcome:
- the site stops feeling like one repeated template and starts feeling like a designed platform

## Phase 6B.4 - Flagship Detail Pages
Objective:
- make the most important records feel publishable and premium

Pages and components:
- flagship production detail pages
- foundational research detail pages
- key archive/media detail pages

Assets needed:
- flagship production visuals
- better PDF/document staging
- possible source thumbnail cleanup

Content work:
- richer summaries
- stronger intros
- improved evidence framing

Expected outcome:
- the best content becomes truly convincing instead of merely well-organized

## Phase 6B.5 - Arabic and Bilingual Refinement
Objective:
- make Arabic feel intentionally designed, not only mirrored

Pages and components:
- Arabic homepage
- Arabic section indices
- Arabic detail pages
- navigation and labels

Assets needed:
- same shared visual system
- Arabic-aware layout adjustments

Content work:
- copy tuning
- label refinement
- Arabic-specific pacing and spacing review

Expected outcome:
- bilingual parity in polish, not only parity in route existence

## Phase 6B.6 - Asset Integration and Polish
Objective:
- fold in generated and cleaned assets once the system is stable

Pages and components:
- homepage
- flagship sections
- section headers
- selective detail-page accents

Assets needed:
- approved Freepik / Nano Banana outputs
- edited/reused existing assets
- optional cleaned icon set

Content work:
- minor line edits only

Expected outcome:
- richer atmosphere without breaking coherence

## Phase 6B.7 - QA and Final Tightening
Objective:
- validate usability, readability, bilingual quality, and consistency

Pages and components:
- all key public routes
- filter behavior
- mobile layouts
- Arabic rendering

Assets needed:
- final optimized crops/exports

Content work:
- final tightening, not broad rewriting

Expected outcome:
- a stable, premium, coherent public platform ready for wider visibility
