# Phase 6 Polish Recommendation

Phase 6 should **polish the structured platform that now exists** rather than reopening the migration.

## Exact Recommendation

Proceed with a polish-focused phase that keeps the current static generator and JSON content model, and concentrate on:

1. visual refinement of the structured pages
2. manual Arabic/English UI QA and copy cleanup
3. stronger archive/media browsing ergonomics
4. transcript and source-document presentation polish
5. selective enhancement of related-content modules and home-page curation

## What Phase 6 Should Not Do

- no framework rewrite
- no CMS migration
- no broad new scraping pass
- no schema reset
- no full brand redesign before the current archive UX is fully stabilized

## Recommended Order

1. Fix any manual QA findings from the new browse/detail routes.
2. Polish typography, spacing, and density across productions, archive, and timeline.
3. Refine the archive browsing UX, especially the relationship between the social and media layers.
4. Improve transcript and document presentation.
5. Reassess whether a public entity layer is justified after the browse polish is stable.
