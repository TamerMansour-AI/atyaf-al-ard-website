# Phase 6B-2 Decisions

## Section Index Decisions
- Treat section index pages as the next highest-leverage surface after the homepage because they define how the archive is actually browsed.
- Keep the shared Phase 6 palette, typography, and component language, but introduce page-specific hero moods so the sections feel related rather than identical.
- Use stronger arrival sequences on every section page instead of leading immediately with filters or card grids.

## Browse And Framing Decisions
- Wrap browse controls inside more intentional section shells so filtering feels like part of the page composition rather than a utility strip.
- Add framing panels before the main library/grid so visitors understand what kind of material they are about to browse.
- Use stats, hero chips, and focused callout blocks to establish context quickly without inventing new factual claims.

## Content Decisions
- Refine only the section-page copy in this phase rather than starting a full-site rewrite.
- Make each page voice align to its function:
  - productions: cinematic and flagship-led
  - research: editorial and evidence-driven
  - timeline: historical and chronological
  - archive: recovered-trace and source-aware
  - community/support: human, practical, mobilizing
  - contact: intentional and guided

## Bilingual Decisions
- Keep Arabic parity as a first-order requirement, not a later polish item.
- Rebuild Arabic section pages with equivalent hierarchy and intent instead of relying on weak mirrored structure.
- Preserve RTL clarity by using the same component system with Arabic-specific heading, spacing, and copy adjustments.

## Technical Decisions
- Limit this phase to shared CSS plus the seven focus section indexes and their Arabic mirrors.
- Preserve current routes, content loading logic, filters, and structured data records.
- Avoid introducing new JS systems or a framework change during this pass.

## Deferred To Phase 6B-3 And Later
- redesign of detail pages
- new visual asset generation
- broader media and transcript presentation work
- finer responsive tuning beyond current checks
- site-wide final polish and consistency harmonization
