# Phase 6B-3 Decisions

## Detail Page Strategy Decisions
- Focus first on the records that define the project publicly and interpretively rather than trying to style every detail page evenly.
- Treat detail pages as the next major quality bottleneck after homepage and section indexes.
- Use one stronger shared detail-page system plus a curated flagship pass, instead of building isolated one-off premium pages.

## Design Decisions
- Extend the Phase 6 design language into detail pages with rich heroes, stronger tonal hierarchy, and clearer section rhythm.
- Differentiate detail-page families through hero mood and narrative framing:
  - productions: cinematic and chapter-led
  - research: editorial and evidence-aware
  - timeline: milestone-driven and historical
  - archive/media: source-aware and contextual
  - community/support: human and mobilizing

## Source / Evidence Decisions
- Make source-awareness more visible inside the detail flow, not only through small metadata chips.
- Prefer honest degradation notes over displaying broken-looking recovered text as if it were trustworthy body copy.
- Keep direct source links, transcript links, and PDF/document access visible near the top of high-value pages.

## Bilingual Decisions
- Start the Arabic flagship detail pass with the highest-leverage records instead of waiting for a full Arabic sweep at the very end.
- Use the shared detail-page system to improve cross-language coherence, but accept that a fuller Arabic record-by-record pass remains for a later stage.

## Technical Decisions
- Keep the existing static architecture and edit the generated detail pages directly.
- Limit this phase to the shared CSS plus selected flagship detail pages and selected Arabic mirrors.
- Validate with the existing repo validator and direct Chrome headless screenshot checks.

## Deferred To Later Phases
- broader detail-page elevation for the remaining records
- deeper transcript/document presentation work
- wider Arabic mirror completion pass for the still-older detail pages
- generated visual asset integration
- full-site final polish
