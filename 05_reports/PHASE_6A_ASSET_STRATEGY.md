# Phase 6A Asset Strategy

## Goal
Build a controlled asset system that raises the site from “structured archive” to “premium cultural platform” without turning it into a generic AI-image collage.

## Asset Principles
- Every generated asset must belong to a coherent visual system.
- Assets should deepen tone, not merely decorate empty space.
- Reuse existing verified assets where they already support truth, continuity, and recognition.
- Do not flood every page with imagery. Use fewer, stronger assets.
- Arabic and English should share the same visual world, not separate aesthetics.

## Freepik / Nano Banana 2 Usage Strategy

### Best later uses
- cinematic hero concepts
- motif-based section art
- symbolic environment textures
- non-literal archival/cultural imagery
- controlled icon or emblem concepts

### Uses to avoid
- replacing every real source image with synthetic art
- generating inconsistent visuals page by page
- making historical claims through fabricated imagery
- using glossy generic “Middle East cinematic” clichés

### Working method
1. Define one visual language first.
2. Generate a narrow concept batch, not dozens of disconnected styles.
3. Choose one approved direction.
4. Derive section variants from that direction.
5. Use editing and cleanup to harmonize reused and generated assets.

## Suggested Asset Families

### Family A: Cinematic environment
- dusk, earth, ember, ash, stone, horizon
- used for homepage, flagship productions, and transitions

### Family B: Research / evidence editorial
- maps, document planes, layered paper, diagrammatic overlays, restrained symbolic marks
- used for research pages, evidence panels, PDF staging

### Family C: Archive / memory textures
- print grain, scanned edge, soft dust, archival paper, signal traces
- used lightly in backgrounds and detail accents

## Risk Controls
- Keep one art director logic across all generated outputs.
- Do not let generated imagery outnumber real evidence visuals.
- Do not place decorative imagery inside evidence-heavy content unless it supports reading.
- Validate Arabic and English page balance before expanding asset count further.
